# HTMX
---
## 1. Atributos de Requisição (Verbos HTTP)

### hx-get="URL": Faz uma requisição GET para a URL especificada.
### hx-post="URL": Faz uma requisição POST para a URL especificada.
### hx-put="URL": Faz uma requisição PUT para a URL especificada.
### hx-delete="URL": Faz uma requisição DELETE para a URL especificada.
### hx-patch="URL": Faz uma requisição PATCH para a URL especificada.

---

## 2. Atributos de Comportamento

## Esses atributos controlam como a requisição é disparada e como a resposta é tratada.

## hx-trigger="evento": Define o evento que irá disparar a requisição. Pode ser um evento DOM (ex: click, change, submit), um evento HTMX (ex: htmx:load), ou eventos especiais como revealed, intersect, load, every < intervalo >.
## Exemplos:

```htmx
hx-trigger="click", hx-trigger="change delay:500ms", hx-trigger="revealed". 
```
### hx-target="seletor CSS": Especifica o elemento no DOM que será alvo da resposta da requisição. O conteúdo retornado pelo servidor será inserido neste elemento.
## Exemplo: 

```htmx
hx-target="#minha-div".
```

### hx-swap="estilo de swap": Define como o conteúdo da resposta será inserido no hx-target.
```htmx
Estilos comuns: innerHTML (padrão), outerHTML, afterbegin, beforebegin, beforeend, afterend, delete, none.
```
### Pode incluir modificadores como settle:300ms para atrasar a remoção de classes de transição.
```
Exemplo: hx-swap="innerHTML settle:300ms".
```
### hx-select="seletor CSS": Permite selecionar apenas uma parte do HTML retornado pelo servidor para ser inserida no hx-target.
### Exemplo: hx-select="#apenas-esta-secao".
```htmx
hx-select-oob="seletor CSS:swap-style": Permite selecionar e inserir conteúdo de fora do alvo principal (Out Of Band).
```
## Exemplo:
```htmx
hx-select-oob="#notificacao:outerHTML".
```
## hx-swap-oob="swap-style": Usado em elementos dentro da resposta HTML para indicar que eles devem ser trocados fora do alvo principal.
## Exemplo:
```htmx
<div id="notificacao" hx-swap-oob="outerHTML">...</div>.
```

## 3. Atributos de Dados e Parâmetros
```htmx
hx-vals='{"chave": "valor"}': Adiciona valores estáticos à requisição.
hx-vars='{"chave": "valor"}': Adiciona variáveis JavaScript à requisição.
hx-params="parâmetros": Controla quais parâmetros são incluídos na requisição.
Exemplos: hx-params="none", hx-params="*" (todos), hx-params="not campo1,campo2".
hx-headers='{"chave": "valor"}': Adiciona cabeçalhos HTTP personalizados à requisição.
hx-include="seletor CSS": Inclui os valores de outros elementos do formulário na requisição.
Exemplo: hx-include="#meu-formulario input".
hx-encoding="multipart/form-data": Define o tipo de codificação para formulários, útil para upload de arquivos.
```

## 4. Atributos de Interação do Usuário

### hx-push-url="URL | true | false": Atualiza a URL na barra de endereços do navegador e adiciona uma entrada ao histórico.
### Exemplos: hx-push-url="/nova-pagina", hx-push-url="true".
### hx-replace-url="URL | true | false": Substitui a URL atual na barra de endereços sem adicionar uma nova entrada ao histórico.
### Exemplos: hx-replace-url="/outra-pagina", hx-replace-url="true".
### hx-boost="true": "Turbina" todos os links e formulários dentro do elemento para usar HTMX, transformando-os em requisições AJAX.
### hx-history="false": Impede que o elemento seja salvo no histórico do navegador.
### hx-history-elt: Marca um elemento como o elemento principal a ser salvo no histórico.

---

## 5. Atributos Avançados

### hx-sse="connect:URL | swap:evento": Conecta a um EventSource (Server-Sent Events) e escuta por eventos.
### hx-ws="connect:URL | send:evento": Conecta a um WebSocket e envia/recebe mensagens.
### hx-ext="extensão": Carrega uma extensão HTMX.
### Exemplo: hx-ext="json-enc".
### hx-on="evento: JavaScript": Permite executar JavaScript em resposta a eventos HTMX ou DOM.
### Exemplo: hx-on::after-request="alert('Requisição concluída!')".
### hx-preserve="true": Preserva um elemento no DOM durante uma troca de conteúdo, útil para elementos como players de áudio/vídeo.
### hx-disinherit="atributo": Impede que um atributo HTMX seja herdado de um elemento pai.
### hx-sync="seletor:estratégia": Sincroniza requisições para um elemento alvo, útil para evitar requisições duplicadas.
### Estratégias: drop, abort, replace, queue.
### Exemplo: hx-sync="this:drop".
### hx-validate="true": Força a validação do formulário antes de enviar a requisição.
### hx-request='{"timeout": 5000, "credentials": "true"}': Configura opções avançadas para a requisição XHR, como timeout e credenciais.
